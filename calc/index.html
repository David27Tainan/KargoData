能力值計算機

在能力值視窗上選職業、打等級、加四圍點數，再選身上的裝備，算出遊戲內能力值視窗（S 鍵）會顯示的攻擊力、防禦、命中、迴避等數值。只包含冒險家職業。頁面最下面是技能試玩舞台。

公式取自遊戲客戶端；buff 與卷軸結果由伺服器決定，請自行輸入。

裝備欄 點方框挑選裝備，每件的數值都能改（例如衝卷）

能力值視窗

HP／MP 為依玩家實測資料推定的近似值，遊戲中每級增加量由伺服器決定。

直接在視窗上改：點「職業」選職業（法師以外二轉後旁邊有分支小選單）、點「等級」打數字、點四圍數字打要加的點數，或按住橘色加號連續加。括號內是「基礎＋加成」，細項的攻擊力、防禦、命中、迴避加成大於 0 紅字、小於 0 藍字。

buff 點一張卡開／關，會用最高等級的數值加到對應欄位

手動輸入 疊加在點選之上

攻擊、魔攻、防禦、命中、迴避填「增加的點數」；速度與跳躍填增加的百分點（例：+20）；四圍％、攻擊％、HP％、MP％填百分比（推定：伺服器決定這些技能寫進哪一欄，這是依數值意義判斷）。buff 不改視窗的技能（魔心防禦、神聖祈禱）不列。

技能試玩 拿真實的遊戲地圖、角色紙娃娃與技能特效素材做的小舞台

先選職業，然後選技能圖示＝設定 Ctrl 施放的技能，數字鍵 1～9 對應目前列的前 9 個；方向鍵走動、Alt 跳躍；舞台王怪會自己走動或站立，點一下也能直接攻擊，雪吉拉戰車死後會分裂成兩隻。按「套用能力值計算機」會用上面算好的職業、等級、四圍、裝備與 buff。

怪物（已選 0 種，勾選後從中隨機出怪）

　

點舞台後用 ← → 移動、↑ ↓ 在繩子旁爬上爬下、Alt 跳、Ctrl 放目前選的技能
