三轉任務

Lv.70 就能三轉。先去冰原雪域找三轉教官，回維多利亞進次元之門打倒自己教官的分身拿黑符，換力量項鍊，再帶黑暗水晶去雪原聖地答 5 題拿智慧項鍊，交回去就轉職。每個職業看自己的 10 步，照順序打勾就好。

次元之門

隱密之地 / 迷霧森林

  1. 走到次元之門（螞蟻礦坑）劍士

    怎麼從「勇士聖殿」走到「螞蟻礦坑」 2 段
    1. 從「勇士聖殿」出來，到「維多利亞港」或「魔法森林」
    2. 搭黑色計程車（五星級計程車，維多利亞港、魔法森林各一台）直接傳送到「螞蟻礦坑」計程車／卷軸

    門在「迷霧森林 / 螞蟻礦坑」 · 在地圖最右邊。點門就會被送進異次元（光明水晶道路）。黑色計程車下車就是螞蟻礦坑，往最右邊走就看到門

  2. 走到次元之門（巫婆森林Ⅱ）法師

    怎麼從「魔法森林圖書館」走到「巫婆森林Ⅱ」 7 段
    1. 在「魔法森林圖書館」走到右下方的傳送點 → 「魔法森林」
    2. 在「魔法森林」走到左下方的傳送點 → 「魔法森林南郊」
    3. 在「魔法森林南郊」走到左下方的傳送點 → 「智慧森林」
    4. 在「智慧森林」走到左上方的傳送點 → 「猴子森林I」隱密之地 看不見的入口
    5. 在「猴子森林I」走到右邊的傳送點 → 「猴子森林Ⅱ」
    6. 在「猴子森林Ⅱ」走到右邊的傳送點 → 「巫婆森林Ⅰ」
    7. 在「巫婆森林Ⅰ」走到右邊的傳送點 → 「巫婆森林Ⅱ」

    門在「隱密之地 / 巫婆森林Ⅱ」 · 在地圖右上方。點門就會被送進異次元（光明水晶道路）。巫婆森林Ⅱ在隱密之地，從魔法森林南郊進智慧森林一路往裡走

  3. 走到次元之門（森林迷宮V）弓箭手

    怎麼從「弓箭手培訓中心」走到「森林迷宮V」 7 段
    1. 從「弓箭手培訓中心」出來回到「弓箭手村」
    2. 搭計程車或用「奇幻村卷軸」到「奇幻村」計程車／卷軸
    3. 在「奇幻村」走到右下方的傳送點 → 「森林迷宮I」 看不見的入口
    4. 在「森林迷宮I」走到左下方的傳送點 → 「森林迷宮II」 看不見的入口
    5. 在「森林迷宮II」走到左下方的傳送點 → 「森林迷宮III」 看不見的入口
    6. 在「森林迷宮III」走到右下方的傳送點 → 「森林迷宮IV」 看不見的入口
    7. 在「森林迷宮IV」走到左下方的傳送點 → 「森林迷宮V」 看不見的入口

    門在「迷霧森林 / 森林迷宮V」 · 在地圖最右邊。點門就會被送進異次元（光明水晶道路）。從奇幻村下方的屋子進森林迷宮，一路走到森林迷宮V

  4. 走到次元之門（猴子沼澤地Ⅱ）盜賊

    怎麼從「墮落城市酒吧」走到「猴子沼澤地Ⅱ」 8 段
    1. 在「墮落城市酒吧」走到右邊的傳送點 → 「墮落城市」
    2. 在「墮落城市」走到左下方的傳送點 → 「沼澤地Ⅰ」戰火之地 看不見的入口
    3. 在「沼澤地Ⅰ」走到最右邊的傳送點 → 「沼澤地Ⅱ」
    4. 在「沼澤地Ⅱ」走到最右邊的傳送點 → 「沼澤地Ⅲ」
    5. 在「沼澤地Ⅲ」走到最右邊的傳送點 → 「鱷魚潭Ⅰ」
    6. 在「鱷魚潭Ⅰ」走到最右邊的傳送點 → 「鱷魚潭Ⅱ」
    7. 在「鱷魚潭Ⅱ」走到左上方的傳送點 → 「猴子沼澤地Ⅰ」隱密之地 看不見的入口
    8. 在「猴子沼澤地Ⅰ」走到下方的傳送點 → 「猴子沼澤地Ⅱ」 看不見的入口

    門在「隱密之地 / 猴子沼澤地Ⅱ」 · 在地圖右上方。點門就會被送進異次元（光明水晶道路）。猴子沼澤地Ⅱ在墮落城市下面的隱密之地

  5. 走到次元之門（火獨眼獸洞穴II）海盜

    怎麼從「航海室」走到「火獨眼獸洞穴II」 4 段
    1. 從「航海室」出來回到「鯨魚號碼頭」，搭鯨魚號計程車回「維多利亞港」
    2. 搭黑色計程車（五星級計程車，維多利亞港、魔法森林各一台）直接傳送到「螞蟻礦坑」計程車／卷軸
    3. 在「螞蟻礦坑」走到最左邊的傳送點 → 「火獨眼獸洞穴I」
    4. 在「火獨眼獸洞穴I」走到右下方的傳送點 → 「火獨眼獸洞穴II」

    門在「迷霧森林 / 火獨眼獸洞穴II」 · 在地圖右上方。點門就會被送進異次元（光明水晶道路）。黑色計程車到螞蟻礦坑後，從最左邊下到火獨眼獸洞穴I，再往下一層就是II

智慧的考驗

艾爾納斯 / 雪原聖地

  1. 回艾爾納斯交力量項鍊

    回到 艾爾納斯酋長官邸，把 力量項鍊 交給三轉教官。他會要你去接受「智慧的考驗」。

  2. 帶黑暗水晶去雪原聖地

    身上帶 黑暗水晶（至少 1 顆，多帶保險）。到「險惡的絕壁II」右上方的傳送點進「雪原聖地」，找 神聖的石頭。

    • 黑暗水晶 ×1

  3. 答對 5 題拿智慧項鍊
